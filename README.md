# 🚗 Potiguar Auto Center

> Website institucional desenvolvido para a **Potiguar Auto Center**, empresa especializada em serviços automotivos, pneus, baterias e manutenção veicular.

🔗 **Website:** https://potiguar-auto-center.vercel.app/

---

## 📌 Sobre o Projeto

O **Potiguar Auto Center** é um website institucional desenvolvido com o objetivo de apresentar a empresa, seus principais serviços e facilitar o contato entre clientes e a oficina.

O projeto foi pensado para oferecer uma experiência simples, moderna e responsiva, permitindo que o visitante encontre rapidamente informações sobre os serviços oferecidos e entre em contato com a empresa.

---

## 🛠️ Serviços

O site apresenta os principais serviços e produtos oferecidos pela Potiguar Auto Center, incluindo:

* Serviços automotivos
* Pneus
* Baterias
* Manutenção e revisão de veículos
* Serviços de oficina
* Atendimento e contato

## 🚀 Executando o Projeto

### 1. Clone o repositório

```bash
git clone <URL_DO_REPOSITORIO>
```

### 2. Acesse a pasta

```bash
cd potiguar-auto-center
```

### 3. Instale as dependências

```bash
npm install
```

### 4. Execute o projeto

```bash
npm run dev
```

O projeto estará disponível localmente no endereço fornecido pelo Vite, normalmente:

```text
http://localhost:5173
```
